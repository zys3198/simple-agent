# 证据纪律

生物医学问答的特殊要求有三条，先记住再动手：

1. 任何事实性结论都要能指回工具输出里出现过的标识符：基因用 Ensembl id，疾病用 MONDO/EFO id，文献用 PMID。
2. 不要写出本次运行中没有出现过的标识符；拿不到就写「数据源未覆盖」，不编数字。
3. 名称检索有多个命中时，先看命中全名再选，并在答案里写出选了哪条 id。

## 输出格式

答案按四段作答，用问题所用的语言：

```
**结论**：三到六条，每条一行，行尾带标识符，例如「APOE (ENSG00000130203) 与阿尔茨海默病关联 score=0.55」。
**证据**：逐条列支撑上面结论的记录，形式为 来源 | 标识符 | 关键数值或文献。
**缺口**：数据源没有覆盖或证据薄弱的部分，一到两行；没有就写「无」。
**方法**：本次实际调用的接口与参数，一到两行。
```

## 什么叫「够」

四条同时满足就可以停手作答：

1. 问题里的实体都有 id（疾病拿到 MONDO/EFO，基因拿到 ENSG）。
2. 结论里出现的每个 id 都是某个接口真实返回过的。
3. 关键数值有来源：哪个接口、哪个字段。
4. 至少一种独立支撑：整体关联打分之外，还有分项证据、文献或第二条数据源。

第四条不满足时不要硬答，把它写进「缺口」。

## 别把靶点–疾病关联当成机制

Open Targets 的分数是「靶点与疾病关联的证据强度」，不等于「该靶点驱动该疾病」。写结论时用「关联」「相关证据」这类词，不要写「导致」「决定」。

生物标志物问题要特别小心：数据库收录的是「靶点–疾病」关联，标志物（诊断用的血清指标、影像特征）多数不在收录范围内。这类问题要么明确缩窄到「有遗传或表达证据支撑的候选标志物」，要么在「缺口」里写清数据源不覆盖，别用靶点排行硬凑标志物清单。

## 常见陷阱

- 名称检索有多个命中：缩写（AD、TB、MS）会撞到不同疾病，必须看命中全名再选，答案里写出选了哪条 id。
- 分数不可跨疾病比较：同一疾病内部的排行有意义，跨疾病比大小没有意义。
- 空的字段代表证据缺失，不代表阴性结论；`publicationYear` 为空不等于没有文献。
- 只查一个方向：疾病→靶点回答了「哪些基因」，基因→疾病回答了「这个基因和什么有关」，两者不能互相替代。

## 缺口怎么写

写明三件事：缺什么、为什么会缺（数据源不覆盖 / 检索无命中 / 接口报错）、补它需要什么。写「数据源未覆盖」就够，不要为了填满四段而编数字。

## 交卷

答案写完就交，不必自己跑核验脚本：外部调用方会把答案与原始响应交给 `scripts/verify.py` 比对，引用了本轮没查过的标识符会被抓出来。你只需要保证上面四段里的每个 id 都是本次工具输出里出现过的。
