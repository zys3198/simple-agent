# 桌面端动效规范

本文件只覆盖 `web/` 这个页面里实际存在的组件与交互。不存在的组件写「不适用」，不做替代设计。

## 1. 体验目标

操作后立刻看见反应，元素的出现、开合、消失都从它自己的位置开始，动作克制到只在需要解释「发生了什么」时出现。

## 3. 全局动效原则

1. **两种缓动，五个时长。** 进入用 `cubic-bezier(.2,.8,.2,1)`（先快后慢），退出用 `cubic-bezier(.4,0,1,1)`（干脆）。时长只有 90 / 160 / 240 / 300 / 140ms 五档：按压 90、微交互与悬停 160、普通进入 240、右栏与大块切换 300、浮层退出 140。浮层退出比进入短 20%–30%。
2. **只动三类属性**：`transform`（位移、缩放）、`opacity`、颜色与背景。高度、`display`、`filter`、`backdrop-filter` 都不参与过渡。
3. **先反馈，再动画。** 点击立刻改状态，动画只描述变化：复制先换勾再淡色，发送先出提问气泡再等模型。
4. **方向与来源一致。** 从触发按钮向下弹的菜单从上方落下，贴在输入框上方的菜单从下往上浮，右栏从右侧推入，新一行从下方上浮。位移都在 6px 以内。
5. **不做队列。** 状态变化用 CSS 过渡与类名切换，同一属性反复改只会从当前计算值继续，动画不排队；Vue 的 `<Transition>` 负责浮层的进入与退出，快速反向会从当前帧接上。
6. **流式内容不加动效。** 逐字追加的正文与思考区没有任何过渡或关键帧，否则每个字都会触发重排与动画。
7. **键盘优先不被动效破坏。** 焦点环即时出现、不淡入；`details` 开合、选中态、禁用态都是状态变化，不做过渡。
8. **减弱动态一档到底。** 系统开启「减弱动态效果」时所有时长压到 0.01ms，位移与缩放归零，颜色、显隐、焦点、错误态照常生效。

## 5. 逐组件状态流程

只列存在的组件。不存在的一律「不适用 / 跳过」，见第 2 节。

**会话行（`.row`）**
默认：无底色，标题 13.5px 深色、元信息 12.5px 灰色。进入：回放时随整块淡入。悬停：浅凹槽底色，160ms。按压：跟随悬停底色，不缩放。聚焦：2px 描边。选中（当前会话）：强调色浅底 + 标题半粗。加载：不适用。成功 / 失败：不适用。禁用：忙碌时点击被忽略，样式不变。快速连续操作：只切换到最后点中的会话。中途取消：点击另一行即改目标。反向操作：点回上一行，底色交叉过渡。

**会话 `⋯` 菜单**
默认：不存在。进入：160ms 从上方 4px 落下淡入。退出：140ms 反向淡化，节点随即移除。悬停项：浅底 160ms。按压项：0.98，90ms。聚焦：菜单项可被 Tab 到，描边即时。选中：不适用。加载：不适用。成功：选「重命名」进入行内输入框，输入框出现即时。失败：「删除」走系统确认框，取消即回到菜单已关状态。禁用：不适用。快速连续：连开连关 6 次只留最后一次状态，无节点残留（实测 0 个）。中途取消：`Esc` 关闭并把焦点还给 `⋯` 按钮（实测焦点回到 `.more` 且 `:focus-visible` 为真）。反向操作：从当前透明度接上。

**`/` 与 `@` 菜单**
默认：不存在。进入：160ms 从下方 4px 浮起。退出：140ms。悬停 / 选中：浅底；方向键移动选中项即时换底，不做滑动。按压：0.99。聚焦：输入框始终持有焦点，菜单不抢焦点。快速连续：输入内容反复触发重算，只渲染最后一个列表；连开连关 6 次实测无残留。中途取消：`Esc` 关菜单，焦点留在输入框。反向操作：从当前帧接上。

**主 / 次 / 图标按钮**
默认：白底细边（主按钮强调色实心）。悬停：底色加深一档或主色加深，160ms，不做抬升。按压：缩到 0.98（图标按钮 0.92–0.94），90ms，抬起立刻回弹。聚焦：2px 描边，即时。选中：不适用。加载：停止按钮只在运行时出现，出现即定型。成功 / 失败：不适用。禁用：不透明度 0.45，不过渡。快速连续：只跟当前按压。中途取消：指针移出即恢复。反向操作：同一属性从当前计算值继续。

**输入框（提问 / 搜索 / 改名）**
默认：提问框是白卡片上的无边框文本区；搜索框是浅灰填充。聚焦：边框转强调色 + 3px 光晕，160ms；光标色取强调色。输入：自动增高，无过渡（每帧都算高度，加过渡会拖慢）。悬停：不适用。按压：不适用。成功：提问发送后输入框立即清空，高度落回单行，无动画。失败：不适用（空输入直接不发送）。禁用：忙碌时仍可输入，发送被忽略。快速连续：回车连按只发第一条（`chat.busy` 拦截）。中途取消：`Esc` 中止当前轮，输入框内容保留。反向操作：不适用。

**右栏（宽屏开合 / 窄屏浮层）**
默认：宽屏是 56px 窄条，条上只有右上角一个展开按钮。进入：300ms `flex-basis` 由 56 到 380，缓出；同一格里的展开按钮换成收起按钮，位置不变、图标镜像。退出：240ms 回到窄条，缓入。悬停 / 按压：展开与收起按钮同图标按钮。聚焦：可 Tab 到。选中：展开后当前页签是强调色浅底加 2px 下划线。加载：不适用。成功 / 失败：不适用。禁用：不适用。快速连续：连开连合 6 次实测宽度依次 380 / 56 交替，最终停在终态，没有排队。中途取消：反向点按从当前宽度接上。反向操作：同上。窄屏：满高浮层从右侧滑入，遮罩同步淡入，`Esc`、遮罩点击、收起图标三条路都能关。

**轨迹记录行**
默认：无底色的行，行首是归属色圆点。进入：新事件到达时 240ms 上浮 6px 淡入。悬停：浅凹槽底色 160ms。按压：不缩放，点击即展开。展开：内容 240ms 下沉 3px 淡入，`pre` 由隐藏变显示。聚焦：可 Tab 到整行（按钮语义）。选中：展开即选中态（浅底保持）。快速连续：流式期间多条记录并发进入，只动 `transform` 与 `opacity`。中途取消：不适用。反向操作：再点即收起，内容立即隐藏。

**引用徽章**
默认：白底细边胶囊，写「引用 N 条」。悬停：字色转强调色，160ms。展开：高度即时变化（`details` 原生），胶囊变圆角卡片并出现阴影。按压：不缩放。聚焦：可 Tab 到 summary。空态：胶囊内写「答案里没有可核验的标识符」。快速连续：反复开合不闪。中途取消：不适用。

**跳到最新**
默认：隐藏（`opacity: 0` + `visibility: hidden`）。出现：160ms 上浮 6px 淡入。消失：140ms 淡出，随后才不可点。按压：0.97。命中：瞬时滚到底，不做平滑滚动（平滑滚动会与用户滚动手感打架）。快速连续：不累积。中途取消：滚回底部立即消失。

**整轮失败 / 工具报错**
默认：不存在。出现：即时，无动画。理由：失败信息必须第一时间被看见，任何淡入都会推迟一帧以上的可读时间。颜色为语义红，与成功态区分。快速连续：多条报错按文档流堆叠。中途取消：不适用。

**键盘焦点与快捷键**
`Tab` 流转顺序按 DOM：左栏 → 标题 → 对话区 → 输入区 → 右栏。焦点环即时出现，不淡入、不缩放。`Enter` 发送、`Shift+Enter` 换行、菜单打开时 `↑ ↓` 与 `Enter` 归菜单、`Esc` 关菜单或中止、`Space` 选中会话行。动画从不改变焦点位置。

**不适用 / 跳过**
路由切换、面包屑、分页、步骤条、拖拽排序、右键菜单、悬停预览、长按、双击、表格、轮播、图片媒体、骨架屏、Toast、通知、进度条、表单校验、原生控件（下拉、单选、多选、开关、滑块、日期）、弹窗（用系统 `confirm`）、权限不足。

## 6. 实现思路

- **一刻度表 + 类名驱动**：所有时长与缓动写成 CSS 变量（`--t-press/--t1/--t2/--t3/--t-out`、`--ease-out/--ease-in`），组件只引用变量，不写具体毫秒。
- **状态用类名与属性切换**：悬停、按压、聚焦、选中、禁用全部由 `:hover`、`:active`、`:focus-visible`、`[aria-current]`、`[aria-selected]`、`:disabled` 驱动，不靠脚本补样式。这样做的好处是中断天然成立：CSS 过渡永远从当前计算值继续。
- **浮层交给框架的过渡组件**：菜单与输入框菜单用 `<Transition>` 包一层，进入与退出分别绑定 `pop` / `pop-down` 两组类，退出时长更短；节点在退出动画结束后才移除。
- **一次性的入场用关键帧**：新一问、新记录、答案落定这类「出现一次」的元素用 240ms 内的短关键帧，不参与反向操作。
- **布局动画只留一处**：只有右栏开合动 `flex-basis`，其余位移一律 `transform`。内容列有固定行宽上限，右栏变宽时文字不重排，只整体位移。
- **不做 JS 性能探测**：没有可靠的、低成本的运行时掉帧检测，靠「只动合成器友好的属性 + 一处布局动画」保底，把降级交给系统的减弱动态设置（见第 7 节）。

## 7. 降级与减弱动态

- **低性能设备**：动效只用 `transform` 与 `opacity`，读屏与布局压力最小；唯一的布局动画是右栏开合，宽度变化时内容列宽不变；不使用 `will-change`、`filter`、`backdrop-filter`、大范围阴影动画。帧时间不足时浏览器会跳过中间帧，最终状态不受影响。
- **动画堆积**：同一元素不叠加多个动画；新状态覆盖旧状态，不排队。
- **减弱动态效果**（`prefers-reduced-motion: reduce`）：所有动画与过渡时长压到 0.01ms、延迟清零、按压缩放归零；颜色、更换图标、展开收起、焦点、错误态照常，只是不再有过程。
- **没有单独的「低性能模式」开关**：本页只有可打印的几个动效，加一个手动开关等于给用户多一个要维护的状态；如将来加入模糊与大位移动效，再补这一档。

## 8. 性能与体验风险点

1. **右栏 `flex-basis` 是布局动画**。300ms 内每帧重排右栏，内容列宽不变所以文字不重排；如果将来把行宽改成随窗口伸缩，这里会变成每帧文字回流，需要改成覆盖式抽屉。
2. **流式追字期间的重绘**。`text_delta` 每来一段就改一次文本节点，所以 `.stream` 与 `.think` 上不能有任何过渡（已确认没有）。
3. **回放时的并发入场**。一次回放可能同时挂载二十多条记录，每条都播 240ms 入场；只动 `opacity` 与 `transform`，合成层压力可控，实测无长任务。
4. **`details` 的展开高度**。原生开合不做高度过渡，因为高度未知且会在内容变化时跳；任何「展开高度动画」都要先测量，代价大于收益。
5. **焦点与浮层**。菜单退出动画期间节点仍在 DOM 里，必须保证它不可点（`pointer-events` 与移除时机）且不抢焦点；当前靠 `<Transition>` 移除时机与「`Esc` 后归还焦点」保证。
6. **连续点击的重复请求**。发送、新建、切会话都受 `chat.busy` 与时序约束，界面不会因为连点产生两条并行流。

## 9. 验收清单

1. 每个可点元素悬停与按压都有可见变化，且按压在 100ms 内可见。
2. 所有进入动画在 300ms 内结束，退出比进入短。
3. 新元素从触发它的位置附近出现：菜单从按钮方向来，记录从下方上浮，右栏从右侧进。
4. 位移不超过 6px，缩放不超过 8%。
5. 快速连点任一按钮 5 次以上，界面停在最后一次操作的结果，没有动画叠加、没有残留节点。
6. 右栏、菜单在动画中途反向操作，能从当前状态平滑接上，不闪跳。
7. 流式回答期间滚动与悬停不卡顿，正文没有逐字动画。
8. 键盘 `Tab` 全页走一遍，焦点环始终可见；`Esc` 关菜单后焦点回到触发按钮。
9. 打开系统「减弱动态效果」后，所有动作即时完成，状态、焦点、错误提示仍然清楚。
10. 窄屏与宽屏来回拖动窗口，右栏在浮层与窄条之间切换，不出现横向滚动条。
